# Indentation Workshop Materials

This repository contains materials for two workshops on indentation data analysis and crystal-plasticity finite-element (CPFEM) modeling.

## Workshop 1: ML clustering

[`Atelier1_ML-Clustering/`](Atelier1_ML-Clustering) contains Excel datasets, analysis helpers, and two Jupyter notebooks:

- `Clustering.ipynb` loads the selected Excel dataset, computes spatial and statistical analyses, and saves figures and intermediate data under `Results/`.
- `LLM_Clustering.ipynb` demonstrates an Azure OpenAI-assisted clustering workflow. It expects `Results/LLM/imported_data.csv`; copy the CSV exported by the clustering notebook into that location before running it.

Run the clustering notebook with the workshop directory as the working directory:

```powershell
cd Atelier1_ML-Clustering
jupyter lab Clustering.ipynb
```

Select a dataset and its worksheet in the notebook's configuration cell before running the analysis. Run the notebook cells from top to bottom.

**Related paper:** [Materials Science and Engineering: A article](https://www.sciencedirect.com/science/article/pii/S092150932601631X?via%3Dihub).

The LLM notebook requires access to an Azure OpenAI deployment compatible with its configured API version and model. Set the credentials in the shell before launching Jupyter; do not put API keys in the notebook or commit them:

```powershell
$env:AZURE_OPENAI_API_KEY = "your-key"
# Optional: override the endpoint configured as the default in the notebook.
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
jupyter lab LLM_Clustering.ipynb
```

## Workshop 2: CPFEM and nanoindentation

[`Atelier2_CPFEM-NI/`](Atelier2_CPFEM-NI) contains:

- `0_preProc/`: Ansys Discovery geometry script and a geometry project file.
- `1_CPFEM-SX-NI/`: A Jupyter notebook that generates an ANSYS Mechanical APDL material-command snippet. Review and adjust its example material parameters before using the generated snippet in a simulation. Run it from this directory:

```powershell
cd Atelier2_CPFEM-NI\1_CPFEM-SX-NI
jupyter lab CP_UMAT.ipynb
```

- `2_postProc/`: A notebook and helper module for comparing CPFEM surface output with AFM measurements. Run it from this directory so its relative `inputs/` and `outputs/` paths resolve:

```powershell
cd Atelier2_CPFEM-NI\2_postProc
jupyter lab surfPlot.ipynb
```

The geometry script uses the Ansys Discovery/SpaceClaim scripting API (`SpaceClaim.Api.V251`) and must be run in the corresponding Ansys script editor, not in a standard Python interpreter. The CPFEM workflow also requires a compatible, licensed Ansys installation; pip dependencies do not install Ansys software or provide a simulation license.

**Additional CPFEM resource:** [STABiX documentation](https://stabix.readthedocs.io/en/latest/) and its [source repository](https://github.com/stabix/stabix). STABiX is a separate toolbox and is not required to run the Ansys examples in this repository.

## Python setup

The Python notebooks and post-processing scripts use Python packages listed in [`requirements.txt`](requirements.txt). From the repository root, create and activate a virtual environment, then install them:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Python 3.10 or newer is recommended. After installing, change to the relevant workshop directory before launching its notebook, as shown above. The Discovery geometry script is the exception: it runs inside Ansys and uses Ansys-provided APIs.

## Repository contents

- [`Atelier1_ML-Clustering/`](Atelier1_ML-Clustering): clustering notebooks, reusable Python helpers, and example datasets.
- [`Atelier2_CPFEM-NI/`](Atelier2_CPFEM-NI): geometry, CPFEM, and post-processing workshop materials.
- [`Workshops_ML-clustering_SX-CPFEM.pptx`](Workshops_ML-clustering_SX-CPFEM.pptx): workshop presentation.

Analysis outputs are written to `Results/` or `outputs/` directories as described above; these directories may need to be generated by running the notebooks. The Azure OpenAI workflow additionally needs a valid API key, endpoint, deployment, and input CSV.
